# Proyek Landing Page Hari 2

Latihan beberapa halaman HTML yang dihubungkan dengan tautan navigasi.

- `index.html` — halaman Home dan tautan ke artikel.
- `tentang.html` — halaman Tentang.
- `kontak.html` — halaman Kontak.
- `profil.html` — halaman profil.
- `blog/artikel.html` — contoh halaman artikel.

Buka `index.html` di browser untuk memulai. Proyek ini berfokus pada HTML dan belum memerlukan proses build.
