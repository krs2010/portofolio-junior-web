# Hari 2 — Dasar HTML

Folder ini berisi latihan HTML untuk membuat formulir, tabel, artikel, profil, dan halaman web sederhana yang saling terhubung.

## Isi folder

- `daftar.html` — formulir pendaftaran dengan input teks, email, nomor telepon, tanggal, pilihan kelas, minat, alamat, dan foto. Beberapa input menggunakan validasi bawaan HTML.
- `tabel.html` — contoh tabel jadwal dengan bagian `thead`, `tbody`, dan `tfoot`, serta penggabungan sel menggunakan `rowspan` dan `colspan`.
- `blog/artikel.html` — halaman artikel sederhana dan contoh tautan kembali.
- `proyek-landing-page/` — latihan beberapa halaman:
  - `index.html` — halaman Home dan contoh tautan.
  - `tentang.html` — halaman Tentang.
  - `kontak.html` — halaman Kontak.
  - `profil.html` — halaman profil dengan bagian tentang, keahlian, dan kontak.
- `img/Gemini_Generated_Image_9b26fj9b26fj9b26.jpg` — aset gambar yang disertakan untuk latihan halaman profil.

## Cara menjalankan

Buka file HTML yang ingin dilihat menggunakan browser. Untuk mencoba proyek beberapa halaman, mulai dari `proyek-landing-page/index.html`, lalu gunakan tautan navigasi pada halaman.

Tidak diperlukan server atau proses build untuk melihat latihan ini.

## Catatan

Formulir pada `daftar.html` diarahkan ke `proses.php`, tetapi file pemroses tersebut belum tersedia di folder ini. Formulir ini digunakan untuk mempelajari struktur dan validasi HTML; pengiriman data belum diproses.
