# Hari 3 — Dasar CSS

Folder ini melanjutkan latihan HTML Hari 2 dengan menambahkan styling CSS pada formulir, tabel, dan halaman profil.

## Isi folder

- `daftar.html` — formulir pendaftaran yang menggunakan `css/style.css`.
- `tabel.html` — tabel jadwal dan daftar aturan kelas, juga menggunakan `css/style.css`.
- `blog/artikel.html` — latihan artikel HTML sederhana.
- `css/style.css` — stylesheet utama dengan variabel warna dan ukuran, reset dasar, layout, tombol, navigasi, kartu, galeri, formulir, tabel, dan aturan responsif.
- `css/coba.css` — stylesheet latihan tambahan.
- `proyek-landing-page/` — proyek beberapa halaman:
  - `profil.html` — halaman profil dengan bagian tentang, layanan, galeri, dan kontak. Halaman ini memakai `../css/style.css`.
  - `index.html`, `tentang.html`, dan `kontak.html` — halaman Home, Tentang, dan Kontak.
  - `img/` — foto profil dan gambar untuk galeri.

## Cara menjalankan

Buka file HTML menggunakan browser. Untuk melihat latihan CSS, mulai dari `daftar.html` atau `tabel.html`. Untuk melihat halaman profil beserta galeri, buka `proyek-landing-page/profil.html`.

Tidak diperlukan proses build atau server untuk melihat halaman-halaman ini.

## Materi yang dipraktikkan

- Mengatur warna, tipografi, jarak, batas, dan bayangan.
- Membuat layout dengan Flexbox dan CSS Grid.
- Menggunakan variabel CSS, pseudo-class seperti `:hover` dan `:focus`, serta media query.
- Menata formulir, tabel, kartu, navigasi, dan galeri gambar agar menyesuaikan ukuran layar.
