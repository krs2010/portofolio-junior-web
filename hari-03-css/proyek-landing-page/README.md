# Proyek Landing Page Hari 3

Versi bergaya CSS dari latihan beberapa halaman HTML.

- `profil.html` — halaman profil dengan bagian tentang, layanan, galeri, dan kontak; menggunakan stylesheet `../css/style.css`.
- `index.html`, `tentang.html`, dan `kontak.html` — halaman pendukung proyek.
- `img/` — gambar profil dan galeri.

Buka `profil.html` di browser untuk melihat halaman yang menggunakan styling. Gambar-gambar diambil dari subfolder `img/`.
