# Hari 5 — Fungsi dan Pengolahan Data

Folder ini berisi latihan JavaScript tentang fungsi, array, objek, modul, dan pembuatan aplikasi kecil.

## Isi folder

- `index.html` — penghitung sederhana dan daftar tugas interaktif di browser.
- `listtugas.html` — latihan daftar tugas dengan fungsi tambah dan hapus serta penghitung.
- `fungsinilai.js` — aplikasi terminal untuk mengelola nilai siswa, melihat statistik, dan menentukan predikat.
- `nilaifungsi.js` — kumpulan fungsi pengolah nilai beserta contoh pengujian menggunakan `console.assert`.
- `arrayObject.js` — latihan pengolahan data peserta menggunakan array dan objek, termasuk `filter`, `map`, `reduce`, `find`, dan `sort`.
- `hari-05-modul/` — latihan modul JavaScript.
- `proyek-2-kalkulator/` — proyek kalkulator dan validasi formulir.

## Cara menjalankan

Buka `index.html` atau `listtugas.html` di browser untuk mencoba latihan interaktif.

Untuk aplikasi terminal, pastikan Node.js terpasang, buka terminal di folder ini, lalu jalankan:

```bash
node fungsinilai.js
```

Program akan menampilkan menu interaktif. Masukkan nilai siswa, pilih menu statistik atau predikat, lalu pilih menu keluar untuk mengakhiri program.

## Materi yang dipraktikkan

- Membuat fungsi yang dapat digunakan kembali dan memisahkan logika dari tampilan.
- Mengolah array objek dengan metode bawaan JavaScript.
- Membaca input pengguna melalui terminal dan merespons interaksi di halaman web.
