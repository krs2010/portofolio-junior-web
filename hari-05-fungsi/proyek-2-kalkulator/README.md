# Proyek 2 — Kalkulator dan Form Validator

Folder ini berisi dua latihan aplikasi web yang menggunakan JavaScript ES Module:

- `kalkulator/` — kalkulator dengan operasi aritmetika, riwayat perhitungan, dan dukungan keyboard.
- `validator/` — formulir pendaftaran dengan validasi nama, email, nomor HP, kata sandi, dan konfirmasi kata sandi.

Setiap aplikasi memiliki folder HTML, CSS, dan JavaScript sendiri. Buka README di folder masing-masing untuk petunjuk menjalankan aplikasi.
