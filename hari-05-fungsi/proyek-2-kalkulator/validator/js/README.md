# JavaScript Form Validator

Skrip validasi formulir berbasis ES Module.

- `aturan.js` — aturan dan fungsi validasi untuk data pendaftaran.
- `app.js` — menghubungkan validasi dengan input formulir, pesan kesalahan, dan hasil pengiriman.

Modul dimuat oleh `../index.html`; jalankan aplikasi melalui server lokal.
