# JavaScript Kalkulator

Skrip kalkulator berbasis ES Module.

- `operasi.js` — logika operasi aritmetika yang tidak bergantung pada DOM.
- `app.js` — menghubungkan logika kalkulator dengan tombol, tampilan, riwayat, dan input keyboard.

Modul dimuat oleh `../index.html`; jalankan aplikasi melalui server lokal.
