# Kalkulator

Aplikasi kalkulator sederhana untuk operasi penjumlahan, pengurangan, perkalian, dan pembagian.

## Fitur

- Tombol angka, titik desimal, operator, hapus satu karakter, dan reset.
- Operasi berantai dan penanganan pembagian dengan nol.
- Riwayat hingga lima perhitungan terakhir.
- Dukungan keyboard: angka dan operator, `Enter` untuk menghitung, `Backspace` untuk menghapus satu karakter, dan `Esc` untuk reset.

## Isi folder

- `index.html` — struktur tampilan dan papan tombol kalkulator.
- `css/style.css` — gaya tampilan kalkulator.
- `js/app.js` — interaksi antarmuka dan penanganan input.
- `js/operasi.js` — fungsi perhitungan yang dipisahkan dari DOM.

## Menjalankan

Karena aplikasi menggunakan ES Module, jalankan melalui server lokal. Dengan Apache XAMPP aktif, buka:

```text
http://localhost/portofolio-junior-web/hari-05-fungsi/proyek-2-kalkulator/kalkulator/
```
