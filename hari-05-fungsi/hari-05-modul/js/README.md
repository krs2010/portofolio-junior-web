# Modul JavaScript Statistik

Skrip ES Module untuk halaman latihan statistik nilai.

- `matematika.js` — mengekspor fungsi untuk menghitung rata-rata, nilai tertinggi, dan nilai terendah.
- `apps.js` — mengimpor fungsi tersebut, membaca input dari halaman, dan menampilkan hasil serta pesan validasi.

Modul dimuat oleh `../index.html`. Jalankan halaman melalui server lokal agar impor ES Module dapat digunakan.
