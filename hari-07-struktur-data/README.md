# Hari 7 — Struktur Data Lanjutan

Latihan lanjutan JavaScript tentang implementasi struktur data, algoritma, dan perapian kode. Folder ini menggunakan ES Module (`package.json` menetapkan `"type": "module"`).

## Isi folder

- `structures.js` — implementasi struktur data yang dipakai oleh latihan.
- `lab1.js` dan `labs1.js` — latihan Linked List dan antrean.
- `lab2.js` — latihan Tree dan Graph.
- `lab3.js` — latihan pencarian dan pengurutan.
- `lab4.js`, `kode-buruk.js`, dan `kode-bersih.js` — latihan perbandingan kode dan praktik clean code.
- `lab5.js` — konfigurasi ESLint untuk pemeriksaan kode.
- `proyek-3-antrian/` — simulator antrean dan riwayat editor; lihat README di dalam folder proyek.

Jalankan latihan Node.js dari folder ini, misalnya `node lab1.js`. Untuk simulator browser yang menggunakan modul, jalankan melalui server lokal.
