# JavaScript Simulator Antrean

Modul JavaScript yang mengimplementasikan dan menghubungkan fitur simulator.

- `structures.js` — struktur data dasar untuk fitur antrean dan riwayat.
- `antrian.js` — logika antrean loket dan riwayat nomor yang dipanggil.
- `riwayat.js` — pengelolaan riwayat teks Undo/Redo.
- `app.js` — penghubung modul dengan DOM dan penyimpanan catatan browser.

Modul-modul ini dimuat oleh `../index.html` dan memerlukan server lokal.
