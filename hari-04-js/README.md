# Hari 4 — Dasar JavaScript

Folder ini berisi latihan dasar JavaScript: variabel dan tipe data, operator, percabangan, perulangan, algoritma sederhana, serta interaksi dengan pengguna.

## Isi folder

- `latihan1.js` — deklarasi variabel, tipe data, operator, template literal, serta perhitungan sederhana seperti luas lingkaran dan konversi suhu.
- `latihan2.js` — contoh algoritma dengan percabangan: ganjil/genap, positif/negatif/nol, tarif parkir, kalkulator, dan kategori BMI.
- `latihan3.js` — latihan perulangan, pola teks, FizzBuzz, penjumlahan digit, dan permainan tebak angka melalui terminal.
- `latihan4.html` — kalkulator BMI sederhana yang menerima input berat dan tinggi di browser.
- `nilai.js` — aplikasi terminal untuk memasukkan nilai siswa, melihat statistik kelas, dan menampilkan predikat serta status kelulusan.
- `pseducode.txt` — pseudocode untuk beberapa algoritma pada latihan percabangan.

## Cara menjalankan

### Skrip JavaScript di terminal

Pastikan Node.js sudah terpasang. Buka terminal di folder ini, lalu jalankan file yang ingin dicoba:

```bash
node latihan1.js
node latihan2.js
node latihan3.js
node nilai.js
```

`latihan3.js` menjalankan permainan tebak angka setelah contoh-contoh perulangan selesai dicetak. `nilai.js` menampilkan menu interaktif; ikuti petunjuk di terminal dan masukkan pilihan 1–4.

### Kalkulator BMI di browser

Buka `latihan4.html` menggunakan browser, masukkan berat dalam kilogram dan tinggi dalam sentimeter, lalu tekan **Hitung**.

## Materi yang dipraktikkan

- Variabel, tipe data, konversi tipe, operator, dan template literal.
- Percabangan `if` / `else` serta pemilihan kategori berdasarkan kondisi.
- Perulangan `for` dan `while`, termasuk perulangan bersarang.
- Input pengguna melalui terminal dengan Node.js dan melalui formulir HTML di browser.
